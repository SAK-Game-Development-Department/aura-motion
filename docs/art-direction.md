# AURA アートディレクション

## 世界観
**暗い虚空に浮かぶ光。** 背景は深い藍から黒へのグラデーション。そこに存在するものは、すべて「光」として描く。
光の色は3色だけで、増やさない。

| 役割 | 色 | 用途 |
|---|---|---|
| 虚空 | `#05060f`（深い藍黒）/ `#020208` | 背景。純黒は使わず、わずかに藍を混ぜる |
| シアン | `#3ff2ff` | プレイヤーの体・左手・Good・安全 |
| マゼンタ | `#ff3fb4` | 右手・迫る危険（回避パートの弾・壁） |
| 琥珀 | `#ffb43f` | Perfect・ゴール・報酬・スコア |
| 白 | `#f4f7ff` | 発光の芯（3色の最高輝度部分）と最小限の文字 |

中間色は、この3色と白の加算合成から自然に生まれるものだけにする。UI のグレーなどは虚空の色の明度違いで作る。

## 動きの言語
- **すべての動きにイージングを付ける**（`src/core/math.ts` の `ease`）。線形の移動は「機械」に見えるので使わない
  - 出現: `outBack`（少し行き過ぎて戻る）。消滅: `inCubic`。迫る: `inOutSine`
- **ヒットは必ず3段で統一する**
  1. **ヒットストップ**（約70ms）: 当たった球と周囲の粒子がわずかに静止する（ゲーム時間は止めない。見た目だけ止める）
  2. **放射**: 琥珀（Perfect）またはシアン（Good）の粒子が放射状に飛ぶ。中心に白い閃光の輪
  3. **余韻**: 粒子が減速しながら消え、背景に波紋が1つ広がる
- ミスは「割れる」のではなく「光が抜けて灰になる」: 彩度と輝度を落としながら下へ沈む。罰ではなく、静かに通り過ぎる

## 情報の伝え方（文字に頼らない）
| 伝えたいこと | 形・色・動き |
|---|---|
| 「いつ触るか」 | 球を囲む輪が縮み、球に重なった瞬間が正解。画面全体も拍に合わせて弱く脈動する |
| 「どちらの手で」 | 球の色（シアン＝左側、マゼンタ＝右側、琥珀＝どちらでも）。ただし判定は、初期設定ではどちらの手でもよい |
| 「立ち位置」 | 人型の枠。シアン＝ちょうどよい、マゼンタ＝近すぎる、琥珀＝遠すぎる。枠自体が近づく・遠ざかる動きをする |
| 「ポーズ」 | 壁に人型の穴。合っている手足から順に穴の縁がシアンに光る |
| 「よける」 | 床すれすれの波＝ジャンプ、頭の高さの帯＝しゃがむ、片側の光の柱＝反対側へ傾く |
| 「流れを導く」 | 琥珀のゴールの輪が脈動し、粒子の川が流れてくる |

文字は最小限に、大きく（画面の高さの5%以上）、ひらがなを多めにする。表示するのは「AURA」、スコア、短い呼びかけ（「てをたたいて」など）、プライバシーの表記だけ。

## 見せ場（作り込む3点）
1. **変身**: 開始時に、骨格の光の線から体の輪郭へ粒子が吸い寄せられ、一気に満ちる（約1.2秒）
2. **流れ**: 数十万の粒子の川に腕を差し入れると、流れが割れて曲がり、腕を振ると尾を引く
3. **Finale**: 球・壁・回避が同時に来て、背景の脈動が最も強くなる。それでも安全基準の範囲内に収める

## 光過敏への安全基準（必須）
- 画面全体の明るさの急変（フラッシュ）は**毎秒3回以下**。1回の明るさの増分は最大0.35（0〜1のスケール）
- フラッシュは立ち上がり40ms、減衰は180ms以上の指数減衰とし、カクッとした点滅にしない
- 赤の飽和色による全画面の明滅は使わない（マゼンタも全画面には使わない）
- 揺れは最大で画面の高さの1.2%程度。強度は設定で0〜100%に下げられる
- **控えめモード**（Kキー または `?calm=1`）: フラッシュ15%、揺れ0%、背景の脈動を弱める
- 実装はすべて `src/render/fx/safety.ts` を経由し、ユニットテストで上限を検証する
