# AURA アートディレクション（術バトル版）

## 世界観
**暗い虚空に浮かぶ光。** 背景は深い藍から黒。存在するものはすべて「光」として描く。光の色は3色に絞り、増やさない。

| 役割 | 色 | 用途 |
|---|---|---|
| 虚空 | `#05060f` / `#020208` | 背景（純黒は使わない） |
| シアン | `#3ff2ff` | 手の骨格・指先の軌跡・「ひらく／つまむ」系の術 |
| マゼンタ | `#ff3fb4` | 「さす／ふたえ／かぎ」系の術・敵の攻撃 |
| 琥珀 | `#ffb43f` | 「にぎる／たてる／つの」系の術・Perfect・空中の印 |
| 白 | `#f4f7ff` | 発光の芯、最小限の文字 |

**色だけで区別しない（色覚多様性への配慮）**: 術の種類は、色に加えて**形**（術のアイコン＝その手の形の光の骨格）と**動き**（放射・直進・螺旋などの軌道）で区別する。
敵の弱点の印も「手の形のアイコン＋動きの矢印や軌跡」で示し、色は補助にとどめる。

## 動きの言語
- すべての動きにイージングを付ける（`src/core/math.ts` の `ease`）
- **ヒットは3段で統一する**: ① ヒットストップ（約70ms。ゲームの時間は止めず、見た目だけ止める）→ ② 粒子の放射 → ③ 余韻の減衰と背景の波紋
- 不発・ミスは「光が抜けて灰色になり、沈む」。罰ではなく、静かに通り過ぎる
- **構え→発動**: 形が認識された瞬間に、手の上にその形のアイコン（光の骨格）が灯り、手のひらの周りの輪が溜めに合わせて縮む。溜めが完了するか動きが入ると発動して弾ける
- 「あと少し」: 形になりかけているときは、最も近い形のアイコンが薄く瞬く

## 情報の伝え方（文字に頼らない）
| 伝えたいこと | 形・動き・光 |
|---|---|
| 手をかざす位置 | 手の形の枠。シアン＝ちょうどよい、マゼンタ＝近すぎる（枠が近づく動き）、琥珀＝遠すぎる（枠が遠ざかる動き） |
| どの形を作るか | 半透明の「ゴーストハンド」がお手本を見せる。敵の弱点の印は、その形のアイコン |
| いつ出すか | 敵の隙の窓を、縮む輪と脈動で示す |
| どの動きか | 印に添える矢印（はらう）、近づく円（おす）、遠ざかる円（ひく）、跳ねる点（はじく）、軌跡（空中の印） |

文字は最小限に、大きく（画面の高さの5%以上）、ひらがなを多めにする。

## 見せ場（作り込む3点）
1. **手が光になって現れる**: 手を出した瞬間、骨格の光の線に粒子が吸い寄せられて手の形に満ちる（約1秒）
2. **空中に描いた印が術になる**: 指先の琥珀の軌跡が、描き終えた瞬間に図形として閉じ、光って飛ぶ
3. **ボス戦の連携技**: 形A→B→Cの連携が成立するたびに演出が段階的に大きくなる

## ジェスチャーの原則（docs/gesture-eval.md と対応）
- 手のひらをカメラに向けて作れる、指の重なりの少ない形を選ぶ
- 両手の指を組む「印」は使わない（既存作品の連想を避ける、自己遮蔽で認識も崩れる）
- 腕を肩より上に上げ続ける必要を作らない（疲労）。すべての技に片手の代替手段を用意する

## 光過敏への安全基準（必須）
- 画面全体の明るさの急変は**毎秒3回以下**。1回の明るさの増分は最大0.35
- 立ち上がり40ms、減衰180ms以上。赤系の飽和色を全画面に使わない
- 揺れは最大で画面の高さの1.2%程度。強度は0〜100%に設定できる
- **控えめモード**（K キー または `?calm=1`）: フラッシュ15%、揺れ0%、脈動を弱める
- 実装はすべて `src/render/fx/safety.ts` を経由し、ユニットテストで上限を検証する
