# ジェスチャー認識の評価（合成データ）

生成日時: 2026-10-22T01:55:31.914Z（`npm run gesture-eval`、所要 8 秒）

> **注意: これは合成データ（パラメトリックな手のモデル＋ノイズ）による評価です。実際の手での精度はまだ測っていません。**
> 実機での評価はジェスチャーラボ（`npm run lab` / https://aura-lab-csq.pages.dev）で記録したデータで行います（手順は末尾）。合成データだけで合格を宣言しません。

## 条件

- 変化させた条件: 左右の手 × 面内回転 5段階（−35〜35°）× 手の向き（yaw）0/25/45° × 大きさ 0.08/0.15/0.28（画面の高さ比）× ノイズ σ 0.003/0.006/0.01 × 大きな外れ値 0/3% = **540 条件**
- 形ごとに「自然な手 → 180ms で形を作る → 900ms 保持 → 戻す」の系列を作り、指の曲がりに ±0.12 のばらつきを加えた（雑な形）
- 判定: 保持中（形が完成した後）に正しい形の「構え」が出れば認識成功。形の完成後に別の形が判定されるか、別の形で技が発動したら誤認識
- 主要な閾値: enterConf 0.68, exitConf 0.45, margin 0.12, 連続 2 フレーム（切り替え 3）, 溜め 380ms

## 合成データの限界（実機で確かめること）

- 合成の手は、指の太さ・自己遮蔽・MediaPipe 特有の推定の癖（親指の位置のずれ、指が重なったときの推定の崩れ）を再現していない
- 照明・ブレ・肌の色・手袋・爪の装飾の影響は、ノイズとして近似しているだけ
- 特に **つの・たてる・かぎ・つまむ** は、実機で自己遮蔽の影響を受けやすいと予想する。実機のデータで不安定なら、ジェスチャーセットから外す（6形に絞る）

## 実機での評価手順（ジェスチャーラボ）

1. ラボを開く（`npm run lab` → http://localhost:5174 または https://aura-lab-csq.pages.dev）。入力を「カメラ」にする
2. 「自動校正」を押して、手を 2 秒ひらく → 2 秒にぎる
3. ラベルを選び「60フレーム記録」を押して、その形を作ったまま、ゆっくり手を回す・近づける・遠ざける。8形それぞれと「なし」（自然な手、会話するときの手の動き）を記録する
4. 記録者タグを変えて、複数の人（手の大きさ・年齢の違う人、可能なら子ども）で記録する
5. 「規則ベースで評価」「kNN で評価」を押して混同行列を見る。再現率 95% 以上、別の形への誤認識 3% 以下、「なし」が形と判定される率が低いことを確認する
6. JSON を保存して共有してください。そのデータで閾値と分類器を調整し、この文書に「実機データ」の節を追加します
