# 展示当日の運用手順

## 1. 設置
```
   ┌─────────── 画面（プロジェクタ / 大型モニタ）───────────┐
   │                                                     │
   └─────────────────────────────────────────────────────┘
               [カメラ] ← 画面の上端か下端の中央、床から 1.0〜1.3 m
                  │
                  │  2.5〜3.5 m（全身が映る距離）
                  │
              （プレイヤーの立ち位置: 床にテープで印を付ける）
                  │
              （1.5 m ほど後ろに観客・列）
```
- **カメラ**: 画面の中央に置き、プレイヤーの方へ水平に向ける。全身（頭〜足首）が映るように。720p / 30fps
- **立ち位置**: 床にテープで「足のマーク」を貼る。左右に 1.5 m ずつの空きを確保する（腕を広げる・左右に傾く動作があるため）
- **背景**: プレイヤーの後ろは、無地で動くものが少ない方がよい（列の人が映り込むと、輪郭抽出が混ざる）。可能なら衝立を置く
- **照明**: プレイヤーの正面〜斜め前から当てる。逆光（背後の窓・照明）は避ける。暗いと警告が出て、判定が自動で緩くなる
- **画面**: 部屋が暗いほど映える。床に光が漏れてもプレイヤーの顔には眩しくない向きにする
- **展示 PC**: 電源接続、省電力モードとスリープを無効にする、OS の通知をオフにする、OS とブラウザの自動更新を当日は止める

## 2. 起動
1. 展示 PC で Chrome（または Edge）を開き、本番 URL（Cloudflare Pages）を開く
   - ネットが不安定なら: ZIP を展開したフォルダで `node serve-local.mjs` を実行し、http://localhost:8080 を開く
2. 初回だけカメラの許可を求められるので「許可」する（以後はブラウザが記憶する）
3. **F キー**で全画面にする（またはブラウザの全画面 F11）
4. 読み込みバーが終わると、タイトル（無人ならデモ）になる
5. 自分で前に立ち、体が光になって 1.5 秒で始まることを確認する

チェック（毎朝）:
- [ ] **D キー**でデバッグ表示を出し、`render webgpu`、`tracking worker/GPU`、fps 55 以上、`capture→tracked` 100ms 以下を確認する（確認したら D で消す）
- [ ] 試しに1回遊び、拍手のキャリブレーションで点が埋まること、球に触れて PERFECT が出ることを確認する
- [ ] 人がいなくなってから 10 秒でタイトルに戻ることを確認する

## 3. スタッフ用キー（来場者には案内しない）
| キー | 動作 |
|---|---|
| D | デバッグ表示（フレーム時間・遅延・粒子数・トラッキング・力場） |
| F | 全画面の切り替え |
| K | 控えめモード（フラッシュ・揺れ・脈動を弱める）の切り替え |
| S | タイトル画面で「座って遊ぶ（上半身モード）」を強制する（来場者は手のボタンでも選べる） |
| M | マウスの緊急モード ⇄ カメラの切り替え |
| R | タイトルに戻す（エラー画面では、カメラの再試行） |

マウスの緊急モードでの操作: マウスで手、Space でジャンプ、C または ↓ でしゃがむ、← → で傾く、1〜9 でポーズ、Z で離席。

## 4. 来場者への声かけ（最小限）
- 「テープの位置に立ってください」だけで十分です。あとは画面の人型の枠の色が案内します（シアン＝OK、マゼンタ＝近すぎ、琥珀＝遠すぎ）
- 子ども・車椅子の方: 画面の「すわって あそぶ」に手を 1 秒かざす（またはスタッフが S キー）。上半身だけで遊べます
- 光の点滅が苦手な方: K キーで控えめモードにする

## 5. トラブル時の復旧
| 症状 | まずやること | それでもだめなら |
|---|---|---|
| 「カメラが つかえません」画面 | USB を挿し直してから **R** キーで再試行。5秒待つとマウスの緊急モードになる | ブラウザを再起動する。カメラが他のアプリ（Zoom など）に使われていないか確認する |
| 体が光にならない／反応が悪い | D キーで `conf`（信頼度）と `luma`（明るさ）を見る。照明を足す・逆光を避ける | 立ち位置を 0.5 m 前後させる。後ろに人が映り込んでいないか確認する |
| カクつく（fps が低い） | D キーで fps と `quality` を見る。自動で粒子数→解像度→エフェクトの順に落ちる | 他のアプリを終了する。電源に接続する。URL に `?quality=1` を付けて起動する |
| 列の人を誤認する | 後ろの人がプレイヤーより大きく中央に映っていないか確認する（プレイヤーは固定されるが、最初の検出時に中央・最大の人が選ばれる） | 列をカメラの画角の外（斜め後ろ）に誘導する |
| 画面が固まった | 5 秒以上止まると自動で再読み込みされる | ページを再読み込みする（Ctrl+R / ⌘R） |
| 判定がずれている気がする | キャリブレーション（拍手）は来場者ごとに自動で行われる。D キーで `judge offset` を確認する | 遅延の大きいカメラ・USB ハブを避ける |

自動で行う復旧（人の操作は不要）:
- 例外が1分間に6回 → タイトルに戻す。トラッキングが3秒止まる、またはカメラが切断される → トラッキングを再起動する
- メインループが5秒止まる → ページを再読み込みする（ループを防ぐため、再読み込みは1分に1回まで）
- 人が離れて10秒 → タイトルに戻る。無人が続くとデモを流す

## 6. 終了時
- ブラウザを閉じるだけでよい。映像は保存していないので、消すデータはない
- ハイスコア（スコアと自動のニックネームだけ）はブラウザの localStorage に残る。消したいときはブラウザの「サイトデータの削除」で消す

## 7. 機能フラグ（URL の `?flags=`）
問題が出た機能だけを止めて展示を続けられます。例: `?flags=-wall,-flow`

| フラグ | 既定 | 内容 |
|---|---|---|
| particles | on | 粒子のシルエット（off にすると光の線の骨格になる） |
| flow | on | 粒子の川を導くパート |
| wall | on | ポーズの壁 |
| dodge | on | 回避パート |
| structure | on | 5部構成（off にすると球だけで90秒） |
| dda | on | 動的難易度 |
| fx | on | ヒットストップ・閃光・揺れ・ブルーム |
| segmentation | on | 輪郭抽出（off にすると骨格から輪郭を作る。軽くなる） |
| worker | on | トラッキングを Web Worker で動かす |
| qr | off | 結果カードの QR（Tier 2、未実装） |
