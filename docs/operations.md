# 展示当日の運用手順

> 流れ: 手をかざす → 校正（ひらく → にぎる → 光に合わせてにぎる、約6秒）→ 戦闘90秒（はじまり → むれ → まもり → ボス）→ 結果 → タイトル。
> 最初の3体は「ゴーストハンド」がお手本を見せ、できるまで待ってくれる（説明なしで覚えられる）。術の一覧は docs/techniques.md。

## 1. 設置（手を使う版）
```
   ┌──────── 画面（モニタ / プロジェクタ） ────────┐
   └──────────────────────────────────────────────┘
                 [カメラ] ← 画面の上端の中央、手を出す高さ（胸〜顔の高さ）に向ける
                    │  0.6〜1.2 m
               （プレイヤーは立っても座ってもよい。手を胸の前に出す）
```
- **カメラ**: プレイヤーの胸の前（手を出す位置）が画面の中央に来るように。手のひらがカメラに向く角度にする
- **距離**: 手を出したとき、手のひらが画面の高さの 1/10〜1/3 程度に映る距離（近すぎ・遠すぎは手の形の枠の色で伝える）
- **背景**: 手の後ろは無地・暗めがよい。後ろの列の人の手が映らない角度にする（小さい手は無視するが、近いと拾う）
- **照明**: 手を正面〜斜め前から照らす。逆光・強いスポットライトの直射は避ける。暗いと警告が出て、3形モードに切り替わる

## 2. 起動
1. 展示 PC で Chrome（または Edge）を開き、本番 URL（Cloudflare Pages）を開く
   - ネットが不安定なら: ZIP を展開したフォルダで `node serve-local.mjs` を実行し、http://localhost:8080 を開く
2. 初回だけカメラの許可を求められるので「許可」する（以後はブラウザが記憶する）
3. **F キー**で全画面にする（またはブラウザの全画面 F11）。このキー操作で**音も鳴り始める**（ブラウザは最初の操作まで音を出さない）。
   操作なしで鳴らしたいときは Chrome を `--autoplay-policy=no-user-gesture-required` 付きで起動する
4. 読み込みバーが終わると、タイトル（無人ならデモ）になる
5. 手をかざし、手が光になって 1.5 秒で始まる（校正: ひらく → にぎる → 光に合わせてにぎる）ことを確認する

チェック（毎朝）:
- [ ] **D キー**でデバッグ表示を出し、`render webgpu`、`tracking worker/GPU`、fps 55 以上、`capture→tracked` 100ms 以下を確認する（確認したら D で消す）
- [ ] 校正で点が埋まること、最初のかげ（ゴーストハンド）を にぎる・ひらく・さす で倒せることを確認する
- [ ] ボスで印（両手）が決まり、カットインが出ることを確認する（片手モードなら代わりの術で）
- [ ] 手を下ろして 10 秒でタイトルに戻ることを確認する
- [ ] 音が鳴ること（環境音と技の音）。大きすぎ／小さすぎなら S の設定パネルで効果音・環境音の音量を調整する

## 3. スタッフ用キー（来場者には案内しない）
| キー | 動作 |
|---|---|
| D | デバッグ表示（フレーム時間・遅延・粒子数・手の21点・特徴量・形の信頼度・状態機械） |
| T | テックレンズ（手の横に関節の角度・形の信頼度・状態、左下に描画方式・粒子数・追跡の速さ・遅延）。既定はアトラクトとリザルトで自動表示。押すたびに 常に表示 → 非表示 → 自動 |
| S | 設定パネル（マウスで操作）: 明るさ・光のにじみ・背景の明るさ・演出の強さ・色ずれ・粒子の数・テックレンズ・両手ポーズのアシスト・全国ランキング送信。この端末に保存され、次の起動でも使われる。「初期値に戻す」あり |
| （音） | 起動後に一度キーかクリックをすると音が鳴り始める（ブラウザの制限。F で全画面にすれば同時に解除される）。音量・ON/OFF は S の設定パネル |
| 1 / 2 / 3 | 難易度の選択画面で 初級 / 中級 / 上級 を選ぶ |
| F | 全画面の切り替え |
| K | 控えめモード（フラッシュ・揺れ・脈動を弱める）の切り替え |
| M | マウスの緊急モード ⇄ カメラの切り替え |
| R | タイトルに戻す（エラー画面では、カメラの再試行） |
| A | 観客向けの画面（audience.html）を別ウィンドウで開く。2台目のモニタ・プロジェクタに移して全画面にする。ライブのスコア、今日のランキング、「しくみ」の説明と実測値を表示する（同じブラウザ内の BroadcastChannel で受け取るので、通信はしない） |

マウスの緊急モードでの操作: マウスで手（人差し指の先）、1〜8 で形（1 にぎる 2 ひらく 3 さす 4 ふたえ 5 つまむ 6 つの 7 たてる 8 かぎ）、クリックでつまむ、
矢印キーで はらう、+/- で おす／ひく、G で はじく、スペースで両手、Z で手を下ろす。

## 4. 来場者への声かけ（最小限）
- 「カメラに手をかざしてください」だけで十分です。手の形の枠の色が距離を案内し、半透明の手（ゴーストハンド）がお手本を見せます
- 片手だけで遊べます（`?onehand=1` で両手の印の代わりに片手の術が要求される）
- 迷っている来場者には「上に出ている手の形をまねして」と伝える
- 光の点滅が苦手な方: K キーで控えめモードにする

## 4.5 全国ランキング（Cloudflare D1）
- 会場のネットにつながっていれば、カメラで遊んで名前を入れた結果が全国ランキングに送られる（スコアと入れた名前だけ。名前を入れなければ送らない）。つながっていなくてもゲームは普通に動く（リザルトに「オフライン」）
- 止めたいとき: URL に `?flags=-online`
- 初回の準備（済み）: `npx wrangler d1 migrations apply aura-scores --remote`、署名の秘密 `npx wrangler pages secret put RUN_SECRET --project-name aura-motion`
- 中身を見る: `npx wrangler d1 execute aura-scores --remote --command "SELECT diff, name, score, region, datetime(at/1000,'unixepoch','+9 hours') FROM scores ORDER BY at DESC LIMIT 20"`
- 不適切な名前・テストの記録を消す: `npx wrangler d1 execute aura-scores --remote --command "DELETE FROM scores WHERE id = <id>"`

## 5. トラブル時の復旧
| 症状 | まずやること | それでもだめなら |
|---|---|---|
| 「カメラが つかえません」画面 | USB を挿し直してから **R** キーで再試行。5秒待つとマウスの緊急モードになる | ブラウザを再起動する。カメラが他のアプリ（Zoom など）に使われていないか確認する |
| 手が光にならない／形が認識されない | D キーで `conf`（検出の信頼度）と `luma`（明るさ）、右上の形の信頼度を見る。照明を足す・逆光を避ける | 手をカメラに 0.3 m 近づける／離す。手のひらをカメラに向ける。ラボ（aura-lab）で形ごとの認識を確認する |
| カクつく（fps が低い） | D キーで fps と `quality` を見る。自動で粒子数→レンズ（色収差）→解像度→エフェクトの順に落ちる | 他のアプリを終了する。電源に接続する。URL に `?quality=1` を付けて起動する |
| 後ろの人の手を拾う | D キーの `ignoredHands` を見る（大きい手が優先され、小さい手は無視される） | 列をカメラの画角の外に誘導する。カメラの角度を下げる |
| 画面が固まった | 5 秒以上止まると自動で再読み込みされる | ページを再読み込みする（Ctrl+R / ⌘R） |
| 判定がずれている気がする | 校正（光に合わせてにぎる）は来場者ごとに自動で行われる。D キーで `judge offset` を確認する | 遅延の大きいカメラ・USB ハブを避ける |

自動で行う復旧（人の操作は不要）:
- 例外が1分間に6回 → タイトルに戻す。トラッキングが3秒止まる、またはカメラが切断される → トラッキングを再起動する
- メインループが5秒止まる → ページを再読み込みする（ループを防ぐため、再読み込みは1分に1回まで）
- 手が見えなくなって10秒 → タイトルに戻る。無人が続くとゴーストハンドのデモを流す

## 6. 終了時
- ブラウザを閉じるだけでよい。映像は保存していないので、消すデータはない
- ハイスコア（スコアと入れた名前だけ）はブラウザの localStorage に残る。消したいときはブラウザの「サイトデータの削除」で消す

## 7. 機能フラグ（URL の `?flags=`）
| フラグ | 既定 | 内容 |
|---|---|---|
| shapes8 | on | 8形（off で にぎる・ひらく・さす の3形） |
| motions | on | 動きで発動（はらう・おす・ひく・はじく） |
| twoHand | on | 両手の技（近づけて→離す） |
| sigils | on | 空中の印（まる・さんかく・いなずま・うず） |
| chains | on | 連携技（P3） |
| structure | on | ステージ構成（P2〜） |
| dda | on | 動的難易度（P2〜） |
| fx | on | ヒットストップ・閃光・揺れ・ブルーム |
| particles | on | 手の GPU 粒子 |
| segmentation | off | 体の輪郭の粒子（Tier 1 の任意要素） |
| worker | on | トラッキングを Web Worker で動かす |
| qr | off | 結果カードの QR |

そのほか: `?stage=easy|normal|hard`（難易度を固定して選択画面を飛ばす。混雑時や体験会向け）、`?onehand=1`（片手モード）、`?calm=1`（控えめモード）
