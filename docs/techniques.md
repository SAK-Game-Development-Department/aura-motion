# 技の一覧（スタッフ・来場者向け）

名前はすべてオリジナル。光・天体・物理の言葉から取った短いカタカナ（スーパーノヴァの系統）で、作った漢字の熟語や「○ノ○」は使わず、かっこよさと分かりやすさのバランスを取っています。
両手ポーズは、両手の指を組まない形です（指を完全に組むと手の認識が崩れるため。既存作品の印の組み方・技名は使っていません）。
（　）の中は、画面に出る手の形の名前です。

## 基本（最初のゴーストハンドが教える）
| 技 | 手の動作 | 見た目 |
|---|---|---|
| フレア | **握る**（グー）を一瞬ためる | 琥珀の光弾 → 放射状に砕ける |
| パルス | **開く**（指を大きく開く） | シアンの輪が三重に広がる |
| レーザー | **指す**（人差し指だけ） | マゼンタの光線 |
| シールド | **開く → 押す**（手を前に押し出す） | 六角形の光の盾（敵の攻撃を防ぐ） |

## 両手ポーズ ── 決まるとカットイン
| ポーズ | 両手の形 | 片手モードでの代わり |
|---|---|---|
| ユニゾン | 両手のパーをカメラに向けて横に並べ、親指の先どうしを付ける | 親指 |
| アンヴィル | 片手のグーと、もう片手のパーを横に並べる（重ねない） | 握る → 押す |
| サーキット | 両手の人差し指の先を合わせる | 握る → 弾く |
| フォーカス | 両手を L 字にして、親指の先どうしを付ける（窓の形） | 鉤 |
| クロスファイア | 両手の二指（V）を内側に傾けて、人差し指の先どうしを付ける（交差させない） | 二指 → 払う |

どのポーズも**手を重ねない**（重なると手の認識が片手を見失ったり 2 つを 1 つにまとめたりする）。カメラに手のひらを向けて横に並べ、触れるのは指先だけにする。

**決めやすくする工夫（アシスト）**: 敵が両手ポーズを求めているあいだは、
- 判定のしきい値を下げ、保持時間を 280ms → 170ms に短くする（指が隠れて形が崩れても、両手の位置関係が合っていれば通る）
- 押し付けた手の片方が一瞬見えなくなっても、0.3 秒はポーズが続いているとみなす
- タイミングの幅を 1.6 倍にする
- 初級・中級では、来る 1.6 秒前から半透明の手でお手本を出す

求められていない両手ポーズは、従来どおり厳しい基準で判定する（離れた両手や片手だけでは出ない。`tests/unit/sealAssist.test.ts`）。

## ゼニス
ボスの両手ポーズの連続＋指で描く図形を決めると「ゼニス」。画面全体が光の輪に包まれ、敵が消える。

## 隠しボス「ボイド」
ボスを倒し、残り時間が **9 秒以上**あると、空間がひび割れて現れる（背景が渦の嵐に変わる）。
- 弱点は 単発の技 3 つ → 両手ポーズ 2 つ → 指で描く図形 1 つ（シードから生成。人の手の限界の間隔を守る）
- 6 つのうち 6 割以上を決めて倒すと「ビッグバン」（+5000）。リザルトに「隠しボス ボイド 撃破！」
- 時間が足りない／ボスを倒せなかったときは、終了 3 秒前まで小さな敵が続けて来るので、最後に何もしない時間ができない

スタッフはキー 1〜3、または URL の `?stage=easy|normal|hard`（難易度を固定）／`?stage=yoi` など（ステージを固定）で選択を飛ばせる。

## ランキング
- **名前**: リザルトで自分で入れる（最大 8 文字）。指先をキーの上で止める／マウスでクリック／キーボード（漢字も可、Enter で決定）。不適切な言葉は登録できない。入れずに離れると「ゲスト」としてこの端末だけに記録（全国には送らない）
- **同じ名前**は同じ人として扱い、難易度ごとに 1 件。前より高い点のときだけ上書きする（ひらがな／カタカナ、全角／半角、大文字／小文字は同じ名前とみなす）
- **この端末**: 難易度ごとの上位（ブラウザの中だけ）
- **全国**: 難易度ごとの本日の上位 5 と、自分の順位（本日・累計）。都道府県とステージ名が付く。
  送るのはスコアとその内訳、自分で入れた名前、ステージ、端末ごとのランダムな ID だけ（映像・手の座標は送らない）。
  カメラで遊んだときだけ送る（自動プレイ・マウスの緊急モードは送らない）。ネットにつながっていなければ「オフライン」と出て、この端末の記録だけになる

## 演出
- 敵の出現: 空間の裂け目が開いて火花がこぼれる
- 撃破: 破片が飛び散り、光の柱が立ち、光が昇る。ボス級ではズームの「パンチ」と色収差
- 10 コンボごと: 下から光の弧が広がり、粒子に衝撃波
- ゼニス: 粒子が中心に吸い込まれる（溜め）→ 光の輪 → 解放の衝撃波
- 光過敏への配慮: 画面全体の明滅は `render/fx/safety.ts` を通す（毎秒 3 回以下）。雷雲の背景も画面全体は光らせない

## 敵
| 敵 | 特徴 |
|---|---|
| 小さな敵 | 弱点が 1 つ。群れで来る |
