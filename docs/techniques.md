# 術の一覧（スタッフ・来場者向け）

名前・用語はすべてオリジナルです。印（いん）は、伝統的な手印（ムドラー）の発想を参考にした、両手の指を組まない形です
（指を完全に組むと手の認識が崩れるため。既存作品の印の組み方・技名は使っていません）。

## 基本の三つ（最初のゴーストハンドが教える）
| 術 | よみ | 手の動作 | 見た目 |
|---|---|---|---|
| 砕光 | さいこう | **にぎる**（グー）を一瞬ためる | 琥珀の光弾 → 放射状に砕ける |
| 波紋 | はもん | **ひらく**（指を大きく開く） | シアンの輪が三重に広がる |
| 閃 | せん | **さす**（人差し指だけ） | マゼンタの光線 |
| 障壁 | しょうへき | **ひらいて → おす**（手を前に押し出す） | 六角形の光の盾（敵の攻撃を防ぐ） |

## 形をふやす
| 術 | よみ | 手の動作 | 見た目 |
|---|---|---|---|
| 双閃 | そうせん | ふたえ（人差し指＋中指） | 二本の光線 |
| 縫 | ぬい | つまむ（親指と人差し指の先を付ける） | 光の糸が敵を縛る |
| 角雷 | かくらい | つの（人差し指＋小指） | 上から落ちる稲妻 |
| 灯 | ともしび | たてる（親指だけ） | 大きな光の玉 |
| 鉤 | かぎ | かぎ（親指＋人差し指で L 字） | 曲がった光の鉤 |

## 動きで放つ
| 術 | よみ | 手の動作 | 見た目 |

| 衝 | しょう | にぎる → おす | 衝撃波の輪が連なって飛ぶ |
| 薙 | なぎ | ひらく → はらう（横に払う） | 白い三日月の斬撃 |
| 弾 | はじき | にぎる → 人差し指をはじく | 光の弾丸 |

| 開闢 | かいびゃく | 両手を近づけて → ぱっと離す | 画面いっぱいに広がる光輪 |

## 印（いん）── 両手。決まるとカットイン演出
| 印 | よみ | 両手の形 | 片手モードでの代わり |
|---|---|---|---|
| 合 | がっしょう | 手のひらを合わせる（指は上） | たてる |
| 拳掌 | けんしょう | 片手のグーを、もう片手のひらに当てる | にぎる → おす |
| 双指 | そうし | 両手の人差し指の先を合わせる | にぎる → はじく |
| 環門 | かんもん | 両手を L 字にして、親指の先どうしを付ける（窓の形） | かぎ |
| 交差 | こうさ | 両手のふたえ（V）を胸の前で交差させる | ふたえ → はらう |

## 奥義
**天輪結界（てんりんけっかい）**: ボス「夜ノ主」の印の連携（3つ）＋空中の印を決めると発動。画面全体が光の結界（回転する輪と放射線）に包まれ、敵が消える。

## 敵（かげ）
| 敵 | 特徴 |
|---|---|
| ちいさな かげ | 弱点の印が1つ。群れで来る |
| まもりの かげ | シアンの殻。2つの術を順に |
| おそう かげ | ふくらんでから襲ってくる → 障壁で防いでから反撃 |
| やぶりの かげ | 琥珀の縁。印（両手）か開闢でないと倒せない |
| 夜ノ主（よるのぬし） | ボス。印の連携 → 空中の印 → 奥義 |
