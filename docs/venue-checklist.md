# 実機でしか確認できない項目（会場・展示PC）

開発環境（カメラなし、ヘッドレスの SwiftShader）では確認できない項目です。展示 PC と本番のカメラ・照明で、
**本番の1週間前まで**に一度、**当日の朝**にもう一度確認してください。結果はこの表の「結果」欄に書き込みます。

測定はすべて **D キーのデバッグ表示**で読めます。

## A. 性能（展示PC）
| # | 項目 | 手順 | 合格基準 | 結果 |
|---|---|---|---|---|
| A1 | 描画のフレームレート | 1人で1プレイし、D キーで `fps` と `frame ema` を見る。Finale（最後の 20 秒）の値を記録する | fps ≥ 55、p95 ≤ 25 ms | |
| A2 | トラッキングのフレームレート | `source` 行の `worker/GPU NNfps` を見る | ≥ 30 fps（カメラが 30fps の場合は 28 以上） | |
| A3 | 品質の自動調整 | `quality P? R? FX?` と `changes` を見る | 1プレイの間に落ちても P1 まで。R と FX が落ちないこと | |
| A4 | 粒子数 | `particles` | 内蔵 GPU で 10 万以上、単体 GPU で 25 万以上 | |
| A5 | 描画のバックエンド | `render` 行 | `webgpu`（WebGL2 の場合はブラウザのバージョンと GPU を確認する） | |
| A6 | トラッキングのスレッド | `tracking` 行と `attempts` | `worker/GPU`。それ以外になった場合は docs/decisions.md D3 に機種と結果を追記する | |
| A7 | 発熱・長時間 | 2時間連続で無人のデモ＋10分ごとに1プレイ。fps と heap を30分ごとに記録する | fps の低下が 10% 以内、heap の増加が 10% 以内、ファンの騒音が許容できる | |

## B. 遅延
| # | 項目 | 手順 | 合格基準 | 結果 |
|---|---|---|---|---|
| B1 | 計測できる遅延 | D キーの `capture→tracked` と `tracked→display` | 合計 ≤ 90 ms | |
| B2 | 体感の遅延（ハイスピード撮影） | スマホのスロー撮影（240fps）で「手を素早く振る」と「画面の手の光」を同時に撮り、コマ数で遅延を数える | ≤ 120 ms（予測あり）。予測なし（config の `LATENCY.predictFraction = 0`）との差も記録する | |
| B3 | キャリブレーションの値 | 3人に遊んでもらい、`judge offset` を記録する | 人によるばらつきが ±60ms 以内、値が -50〜+150 ms | |
| B4 | 判定の手応え | 3人に「タイミングぴったりで触ったのに GOOD／MISS になった」が無いか聞く | 違和感の報告が 1人以下 | |

## C. 照明・トラッキング精度
| # | 項目 | 手順 | 合格基準 | 結果 |
|---|---|---|---|---|
| C1 | 本番の照明での信頼度 | 立ってゆっくり腕を回す。`conf` と `jitter` を見る | conf ≥ 0.75、警告（くらいので…）が出ない | |
| C2 | 暗い場合のフォールバック | 照明を半分にする | 警告が出て、判定が広がる（`UNSTABLE→wide windows`）。プレイが成立する | |
| C3 | 逆光 | プレイヤーの後ろに明るい窓や照明がある状態を試す | 輪郭が崩れる場合は設置を変える（運用で対処する） | |
| C4 | 服装 | 黒い服、白い服、スカート、帽子で試す | どれでも開始でき、球に触れる | |
| C5 | 子ども（身長 110 cm 前後） | 立ち位置ガイドに従って開始する | ガイドだけで開始でき、球に手が届く | |
| C6 | 上半身モード | 椅子に座って「すわって あそぶ」に手をかざす | 開始でき、球・壁・回避（傾く・頭を下げる）が成立する | |
| C7 | 車椅子 | 可能なら実際に試してもらう | C6 と同じ | |

## D. 複数人・交代
| # | 項目 | 手順 | 合格基準 | 結果 |
|---|---|---|---|---|
| D1 | 後ろに人がいる | プレイヤーの 1.5 m 後ろに 2〜3人立つ | プレイヤーのロックが外れない。「ひとりずつ あそんでね」が出るのは画面に入ったときだけ | |
| D2 | 横から人が入る | プレイ中に別の人が画面の端を横切る | ロックが外れない | |
| D3 | 交代 | プレイヤーが離れ、すぐ次の人が立つ | 新しい人として扱われる（キャリブレーションをやり直す） | |
| D4 | 一時的な遮蔽 | プレイヤーの前を人が 0.5 秒横切る | ゲームが継続する（0.8 秒までは保持する） | |
| D5 | 無人での復帰 | プレイ中に立ち去る | 10 秒でタイトルに戻り、デモが流れる | |
