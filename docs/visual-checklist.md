## 術バトル（戦闘）── ヘッドレスで撮影して確認・修正したこと
| 確認したこと | 結果・対応 |
|---|---|
| 影の敵 | 暗い本体の輪郭が揺らめき、マゼンタの縁が光る（通常のブレンドで「光の中の闇の穴」として見える）。倒すと内側から燃えるように溶ける |
| 弱点の印 | 敵の上に、その手の形の光のアイコン（印なら両手のアイコン、空中の印は描き順が光る軌跡、動きは矢印・輪・跳ねる点） |
| ボスの印 | 敵の上に置くと画面の外にはみ出していた → 画面上端に近い・大きい敵は、印を横に出すようにした |
| 文字の重なり | 区切りの文字（「夜ノ主」など）が敵に重なっていた → 画面の下側（70%の位置）に移した |
| 両手の溜めの輪 | 両手を近づけると大きな輪が重なってうるさかった → 輪を小さくした |
| 奥義のカットイン | 上下の黒帯 → 斜めの墨の帯 → 大きな漢字「天輪結界」が拡大しながら定まる。背景は琥珀の結界（回転する輪と放射線）に変わる |
| 背景のステージ | 宵の湖（地平線の霧）→ 星の回廊（ワープの筋）→ 結晶の洞（六角格子。最初は強すぎて敵が見にくかった → 線を細く暗くした）→ 月蝕の天 → 虚空の嵐（隠しボス）。1.5 秒で切り替わる |
| レンズ | 色収差の中心に null を渡すと画面全体が黒くなっていた → 修正。大技の瞬間だけ強くなる |
| 隠しボス | ひび割れ → カットイン「暁ノ影」→ 白い光輪の敵（5 つの眼、周りを回る破片）。隠し奥義「極光天穿」のカットインと結界 |
| テックレンズ（T） | アトラクトとリザルトで、手の横に関節の角度・形の信頼度・状態、左下に描画方式・粒子数・追跡の速さ・遅延が出る |
| 難易度の選択画面 | 三枚のカード（初級=マゼンタ／中級=シアン／上級=朱）。手をかざしたカードが光って拡大し、下端のバーが溜まる。後ろの背景もそのステージのものに変わる |
| ステージごとの敵 | 宵ノ湖=揺らめく影と二つの眼、星ノ回廊=縁の鋭い六角柱と縦長の一つ目（主は回る六角の枠）、紅蓮ノ原=炎の形とつり目・角・火の粉（主は炎の冠） |
| リザルトの表記 | 「奥義天輪結界成功」が途中で折り返していた → 折り返さないようにした |
| カットインの書体 | Windows/mac では「游明朝／ヒラギノ明朝」の太字になる（ヘッドレスの Linux では代わりのゴシックで表示された） |

# 見た目の確認項目

## 自分（Claude）で確認したもの（ヘッドレス Chromium + SwiftShader）
ヘッドレスでも WebGPU（SwiftShader）と WebGL2 が動くので、スクリーンショットを撮って確認した。
SwiftShader では粒子 3 万個で 1fps を下回るため、粒子を含む見た目は**仮想時間モード**（`?vt=1`。1フレームごとに 1/60 秒進む）で撮影した。

| 確認したこと | 結果・対応 |
|---|---|
| 色空間 | 最初は、パレットの sRGB 値をそのまま線形空間のシェーダに渡していたため、背景が灰色っぽく白んでいた → `hexToLinear` で変換して修正した。深い藍黒になった |
| 背景の環境粒子が多すぎて「雪」や「ノイズ」に見える | 明るさを 0.16 から 0.02 に、大きさを 0.75 から 0.55 に下げた。体の周りに粒子が押しのけられた「暗いオーラ」ができ、体のシルエットが際立つ |
| 体の粒子が輪郭にだけ集まり、中が空洞になる | 体の内側の縁付近で内向きのドリフトを加えた |
| キャリブレーションの表示 | 左右からシアンとマゼンタの光が胸の前に集まり、合わさる瞬間に琥珀の輪が出る。拍手を検出すると白い輪が出る。点の数で進み具合が分かる |
| Flow（ながれ） | 琥珀のゴールの輪と発生源が表示され、背景がやや暖色になる |
| HUD | スコアは右上、セクションのアイコンは左上、時間のバーは下端。文字は大きく、最小限にした |
| WebGL2 へのフォールバック | 同じ見た目で描画される（`?webgl=1`） |

スクリーンショットは `npm run e2e` で `test-results/` に保存される（flow-results.png、attract.png、debug-overlay.png、camera-title.png、camera-error.png）。
